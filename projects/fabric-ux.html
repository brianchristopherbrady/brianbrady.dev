Enterprise UX / parity / AI workflows

Fabric UX web component library

Agentic design-to-code work for dense enterprise surfaces: Figma spec review, component parity, accessibility expectations, repository context, and implementation paths that respect the system already in production.

What matters here

  • Map designs to existing components before inventing new UI.
  • Check behavior, composition, accessibility, and product constraints before declaring parity.
  • File actionable gaps when the system cannot meet the design.
  • Reduce component-selection guesswork and one-off implementations that drift from the system.

Constraint set

The interesting work is often in the constraints: what the design asks for, what the component actually supports, what the product already depends on, and what an AI agent must be prevented from making up.
