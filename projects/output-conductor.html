Output Conductor

A visual workflow execution monitor and debugger for Output.ai pipelines. Real-time traces, cost analytics, evaluator results, and execution timelines — all rendered through a performant, virtualized interface that handles thousands of workflow runs without breaking a sweat.

What it does

Conductor gives developers instant insight into their AI pipelines. It renders execution lists, step-by-step detail panels, timeline swimlanes, and trace tables — all backed by virtual scrolling so the UI stays fast with 500+ executions and 2,000+ traces loaded simultaneously.

  • Virtualized execution list via @tanstack/react-virtual.
  • Step-by-step detail with traces, evaluations, retries, and cache state.
  • Gantt-style timeline swimlanes grouped by workflow type.
  • Virtualized trace table across LLM calls, HTTP requests, tool invocations, and evaluations.
  • Analytics dashboard with cost trends, provider breakdown, and daily execution charts.
  • Real-time filtering: search, status, and workflow filters with instant response.

Design decisions

  • UI virtualization renders only visible rows for smooth performance at scale.
  • Split-pane master-detail layout with animated width transitions via Framer Motion.
  • Progressive disclosure: step cards show summary, expand inline for traces and evaluations.
  • Status-driven color system — emerald/indigo/red/amber mapped consistently across components.
  • Dark theme built for developer tools with zinc-950 backgrounds and high-contrast data.

Architecture

  • components/dashboard/ — ExecutionList (virtualized), ExecutionDetail.
  • components/timeline/ — TimelineView swimlane visualization.
  • components/traces/ — TracesView virtualized trace table.
  • components/analytics/ — AnalyticsPanel with Recharts metrics.
  • hooks/ — useWorkflowData for state management.
  • data/ — Mock generators matching the Output.ai schema.

Why it belongs

Conductor is the same instinct applied to observability: take a complex data domain (AI pipeline telemetry), give it a typed schema, render it through a virtualized UI that handles real-world scale, and make the whole thing navigable enough that a developer can diagnose a failure in seconds instead of minutes.
