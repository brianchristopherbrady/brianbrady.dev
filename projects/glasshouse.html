Agent observability / evidence modeling / in progress

Glasshouse

An observability foundation for agentic software-development workflows. The current repository contains TypeScript domain contracts, a frontmatter parser, and Fastify API routes backed by Prisma.

The central question is what an agent actually did, and what evidence supports that account. A configured skill is not necessarily a loaded skill; a declared workflow is not proof of the steps a run executed.

Evidence before presentation

Facts carry a source and a confidence level: observed, strong, inferred, or unknown. Skill evidence separately distinguishes availability, configuration, loading, references, and execution evidence.

These distinctions belong in the data contract before they become badges or diagrams. Collapsing them into a single used/not-used flag would make an eventual interface more certain than its evidence.

Run-level inspection

Server routes cover runs, nested traces, events, file operations, agent handoffs, skill usage, tool calls, logs, GitHub activity, metrics, and stored drift findings. Telemetry endpoints validate incoming events against shared Zod schemas before persistence.

Drift types describe differences such as unexpected files, new tools, missing expected steps, and different outputs. A difference is not itself evidence of malicious intent.

Architecture direction

Shared domain and parser packages separate interpretation from transport. Run traces and evidence metadata provide a foundation for connecting configuration, runtime activity, and resulting artifacts.

The portfolio value here is the modeling work: making uncertainty and provenance explicit enough that a future visualization can remain inspectable.

Current status

This is an in-progress foundation, not a shipped observability dashboard. The inspected web source directory is empty. Existing API and schema code does not establish a functioning ingestion deployment or an automatic drift-detection engine.

No production readiness, live integration, or end-to-end runtime verification is claimed here.
